# Life-os
A customizable personal life dashboard for tracking goals, habits, workouts, finance, and motivation quotes.

A single-page personal dashboard contained in one HTML file with embedded CSS and JavaScript.

## Features
- Goal tracking
- ASAP tasks
- Sprint planning
- Daily habits
- Workout tracker
- Finance tracker
- Quote vault

## Tech
- HTML
- CSS
- JavaScript

## Run
Open `index.html` in your browser.
